Run any LLM on your own laptop with Ollama

2026-08-29 · ollama/ollama

The exact command

ollama run llama3.2

What it is

A one-binary local model runner from Ollama Inc. that pulls quantised weights and serves them on an OpenAI-compatible port.

What to make with it

  • A private code assistant that never leaves your machine
  • Batch-summarise a folder of PDFs offline on a flight
  • A local API your scripts can call without a key or a bill

Skip it if

You have under 8 GB of RAM, or you need frontier-model quality.
